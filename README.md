# Lapis Tool

A compact desktop all-in-one media tool powered by Python and CustomTkinter for converting files and downloading content from various platforms. Designed to be fully portable, it requires no complex installation or repository cloning to run.

---

## Features

* **Universal Media Downloader:** Download videos, audio, and playlists from multiple online platforms.
* **File Converter:** Convert images, videos, audio files, and documents between popular formats.
* **Modern UI:** Clean, responsive desktop interface built with `CustomTkinter`.
* **Portable:** Ready to run out of the box without installation.

---

## Usage

1. Download the latest release or executable.
2. Run the application directly.
3. Enjoy converting your media and downloading online content!

---

## Tech Stack

* **Language:** Python
* **GUI Framework:** CustomTkinter
* **Core Utilities:** FFmpeg (for media conversion), yt-dlp (for downloading)
